# GeoLibre GitHub 版 Codex 技能

本資料夾是需要 GitHub 自架、GitHub Pages、GitHub Actions、長期公開網址與完整 Git 版本留痕時使用的進階版技能。

固定觸發語：

`使用 GeoLibre GitHub 版技能`

只有使用者明確點名 GitHub 版，或明確要求 GitHub 自架／Pages／版本留存時才使用本技能。

一般的：

`使用 GeoLibre 技能`

不得觸發此資料夾，而應使用：

`skills/geolibre-analysis/`

本技能正式路徑：

`ymguan3-boop/audit-codex-skills/skills/geolibre-github-analysis/`

適合：
- 所有成果都要有長期公開 URL；
- 需要 Git commit / Action / Pages 留痕；
- 大型資料或多檔案長期託管；
- 機關內部固定網址或自有部署；
- 不希望把 GeoLibre project 上傳官方 Share。
