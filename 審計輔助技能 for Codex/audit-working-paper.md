# 生成工作底稿技能

> 本技能依審計第二大腦 vault 之 CLAUDE.md 中「工作底稿生成規則」及「查核意見分類規則」規範撰寫。
> **先備條件**：需已完成審計第二大腦安裝及設定（audit-secondbrain-setup），vault 中已有 CLAUDE.md 及對應目錄結構，且 `資料處理/3.查核意見/` 中已有可供參考之查核意見案例。

## 工作流程

### 第一步：使用者提供查核主題

使用者對 OpenCode 說：
```
請幫我根據 [主題] 生成工作底稿，
相關資料在 資料蒐集/ 及 資料處理/3.查核意見/ 中。
```

你應：
1. 讀取 `資料蒐集/` 中的查核資料
2. 讀取 `資料處理/3.查核意見/` 中相關案例作為參考
3. 依工作底稿生成規則，產出四階段結構的標準化底稿
4. 每份同時產出 MD 檔及 WORD 檔
5. 儲存至 `資料庫建置及產出/工作底稿/`

### 第二步：依工作底稿生成規則產出

#### 角色設定
- 應以「資深審計人員」角度進行生成

#### 參考來源
1. `資料蒐集/` 中的查核資料
2. `資料處理/3.查核意見/` 中相關案例

#### 生成結構（四階段）

##### 1. 標題
- **粗體**、200字內
- 首段摘要查核標的項目
- 中段摘要查核事實內容
- 格式：「機關+事項+缺失摘要+允待/允宜/允應...，以...。」
- 尾段需呼應擬議處理意見

##### 2. 依據
- 引用行為時之法令/規定/函文
- **全段文字截錄**（不摘要）
- 依查核事實內容順序對應擇選
- **注意事件發生時間點**以截取行為時之法令

##### 3. 查核事實
架構為：
- **機關主體** + **查核標的（規模/金額）** + **執行情形/現況（含大事記）** + **缺失分析（惟查...核有...疏失/核欠妥適）**

##### 4. 擬議處理意見
- 200字內
- 與標題尾段呼應
- 可用「綜上/鑑於」開頭結合查核事實推論總結

## 參考資料：查核意見分類與應用

### 查核意見分類規則

當需要從既有調查報告中提取查核意見作為工作底稿參考時，依以下規則分類：

**第一層（主要分類）**：依查核主題區分
- 例如：工程品質、採購程序、財務管理、內部控制等

**第二層（次分類）**：依意見類型區分
- 建議事項
- 查明處理事項
- 注意事項

**第三層**：依性質區分
- 洞察（發現潛在問題）
- 前瞻（預防性建議）
- 監督（追蹤改善）

**第四層**：查核意見標題及文章內容
- 直接摘錄查核意見原始內容
- 每個意見末尾註記：「（截取自：[調查報告名稱]）」

### 查核意見章節提取方法

當從調查報告中提取「查核意見」章節時：

1. **定位章節**：掃描 MD 內容，尋找標題中包含「查核意見」的行（支援 `# 查核意見`、`## 查核意見`、`**查核意見**` 等格式）
2. **提取範圍**：從「查核意見」標題下一行開始，至下一個同層級或更高層級標題為止（或檔尾）
3. **分割意見項目**：將提取出的內容依 `**一、**`、`**二、**` 等中編號粗體標題逐項分割，每項獨立為一個查核意見
4. **註記來源**：在每個分割出的意見末尾附加「（截取自：[報告名稱]）」
5. **存放**：獨立存為一個 MD 檔，放入 `3.查核意見/`

### 查核意見總整理與查核意見明細（自動維護）

每次執行 `/資料處理` 並完成分類清理後，系統會自動執行以下五步驟：

1. **掃描** `資料處理/3.查核意見/` 下所有 MD 檔案（排除 `查核意見總整理` 及 `查核意見明細` 本身）
2. **提取**每個檔案中的查核意見：
   - 標題：以 `**` 包圍之中文編號粗體文字（如 `**一、...**`、`**二、...**`），須排除非意見之粗體文字（表數字、附錄章節、壹貳參等章節編號）
   - 內容：標題所在行後至下一個標題行或檔尾之全文
   - 出處：從 frontmatter 或檔案原始名稱取得
   - 年度：從檔名標記取得
   - 附圖附表：從內容中 `[詳附件` 索引取得
3. **去重**：對每筆意見的**本文全文**計算 MD5 雜湊值，建立已見過之 MD5 集合；僅保留首次出現之條目，後續相同 MD5 者全部跳過。去重**跨所有檔案**（同一意見若同時出現在「完整報告」與「提取版」檔案中，僅保留首次出現的一份）
4. **分類**：依標題關鍵字自動判斷主題類型（如：工程品質、採購程序、財務管理、轉運站管理等）及意見分類（查明處理事項/建議事項/注意事項）
5. **產生**兩份文件，以當日日期（民國年月日）作為檔名後綴，存放於 `資料處理/3.查核意見/`：
   - `查核意見總整理(YYYYMMDD).md` — 摘要統計表（含主題類型、分類、年度、筆數、去重紀錄等）
   - `查核意見明細(YYYYMMDD).md` — 逐條完整版（含編號、主題類型、分類、出處、年度、標題、內容、附圖附表索引）

產生工作底稿時，可從 `查核意見明細` 中快速查找相關案例作為參考。

## 常見工作底稿生成範例

以下為使用者常見的請求方式：

| 使用者說 | 你應如何回應 |
|---------|------------|
| 「幫我根據 [主題] 生成工作底稿」 | 讀取 vault 中相關資料，依四階段結構產出底稿 |
| 「幫我根據這些查核事實生成工作底稿」 | 直接使用使用者提供之事實資料產出底稿 |
| 「幫我搜尋查核意見中關於 XXX 的案例來參考」 | 搜尋 `3.查核意見/` 中相關案例，列出供使用者參考 |

## 產出格式要求

- **MD 檔**：依四階段結構撰寫，frontmatter 包含 title、date、type、tags
- **WORD 檔**：依同樣四階段結構以 docx 格式產出
- 每份底稿同時產出 MD 及 WORD 兩種格式
- 儲存至 `資料庫建置及產出/工作底稿/`
